  1.準備
    このディスクには、使用出来るディレクトリ構成をそのまま収録
    しています。このドキュメントが存在する saturnディレクトリ以下を
    まとめてコピーします。
    コピーを行う際には、転送先のディスクに十分な空き容量があるか確認の上、
    作業を行って下さい。
    全てのファイルをコピーするには、約 90Mバイト以上の空き容量が必要です。
    サンプルプログラムや ライブラリのリコンパイルをするには、さらに空き容量
    が必要です。
    コピーが成功したことを確認したら、次に各種ツールが動作出来るよう、
    環境の設定を行います。

  2.環境の設定
    セガサターンの開発環境には 日立SH C環境と gnu環境がありますが、
    それぞれ設定が必要です。

   2.1.SH C コンパイラ等の入手方法
    今回のディスクには日立製"SH C  コンパイラ"等、日立製品は含まれて
    おりません。入手についてはNiftyserveの技術情報フォーラムのデータ
    ライブラリからダウンロードするか、若しくは弊社テクニカルサポート
    センターまでお問い合わせ下さい。

   2.2.SH C コンパイラの環境設定
    SH Cコンパイラのインストーラは、デフォルトでは /shにインストール
    しようとしますが、セガサターンのライブラリやサンプルプログラムで
    は /saturn/sh/以下に格納されていることが前提となっていますので以
    下のような構成になるようインストールして下さい。 GUISHを利用する
    時や、 EVAボードを用いる際には、併せてそれらの附属ソフトも以下の
    ような配置とすることをおすすめします。

    /lib以下には何種かの標準ライブラリがインストールされていますが、
    セガサターンではSHCNPIC.LIBのみを用いますので、 これ以外の標準ラ
    イブラリファイルは消去しても差し支えはありません。
    逆に、SHCNPIC.LIB 以外のコンパイラ付属の標準ライブラリは、サターン
    開発時には、絶対に使用しないで下さい。
    また、SYSROF形式をバイナリへ加工するROF2BIN、 SuperH用クロスア
    センブラのセットASMSHも/saturn/sh/binへインストールしておきます。

        SATURN --|
                 |
                 | -- SH --|
                 |         |-- BIN     実行バイナリ
                 |         |-- INCLUDE インクルードファイル
                 |         |-- LIB     ライブラリ
                 |         |-- SAMPLE  SH Cコンパイラサンプルコード
                 |         |

    SH Cコンパイラには動作環境を示すために環境変数を設定しておく必要
    があります。これらのファイルがC:ドライブ配下に格納されているとす
    ると、以下のように実行環境を設定するバッチファイルへ記述します。

    SET SHC_LIB=C:\SATURN\SH\LIB
    SET SHC_INC=C:\SATURN\SH\INCLUDE
    SET SHC_TMP=C:\TMP
    SET DOS16M=0:16M
    SET DOS4G=quiet
    SET HLNK_LIBRARY1=C:\SATURN\SH\LIB\SHCNPIC.LIB

    SHC_LIBは、SH Cコンパイラがリンクする標準ライブラリが格納されている
    パスを指定します。
    SHC_INCは、SH Cコンパイラが参照する標準インクルードファイルが格納
    されているパスを指定します。
    SHC_TMPは、SH Cコンパイラが作業用として一時的にファイルを書き出す
    パスを指定します。
    DOS16MはDOSエクステンダが利用するメモリ空間を指定します。
    DOS4GはDOSエクステンダが呼ばれた際に標準出力へ現れるメッセージ出力
    を制御します。例ではquietとして標準出力を抑圧しています。
    HLNK_LIBRARY1はSH リンカがリンクする、標準ライブラリファイルを
    指定します。
    最後に、AUTOEXEC.BAT等で設定するファイルサーチパスに、上記の実行
    ファイルが格納されているパス C:\SATURN\SH\BINを追加します。
    例を下に示します。

    SET PATH=C:\windows;c:\bin;c:\dos;c:\saturn\sh\bin;c:\saturn\segabin\bincd
     ( c:\saturn\sh\bin が目的のパスです。)
     ( c:\saturn\segabin\bincd は、その他のツールのインストール先です。)

   2.3.SH Cコンパイラ以外の日立環境ツールの設定
    GUISHやE7000PC ICE、EVAボードを利用する際には以下のような環境変数も
    設定することを忘れないで下さい。詳細は各機器のマニュアルをご参照下
    さい。

    GUISHPATH=C:\SATURN\SH\GUISH
    E7000SYS=C:\SATURN\SH\IPI,1B,D8

    Windows95使用時ではDOSプロンプトのプロパティ中、バッチファイルという
    項目があります。  ここに上記の環境変数の設定を行うバッチファイルを指
    定すれば、 DOSプロンプト起動時に自動的に設定されます。
    PC起動時に、AUTOEXEC.BAT 内で設定してもどちらでも構いません。

   2.4. gccの環境設定
    gccもSH Cコンパイラと同様に動作環境の指定は環境変数によって行います。
    セガサターンの一部ライブラリやサンプルプログラムでは、日立製SH アセン
    ブラASHSMとのソースコードの共用をはかる目的でgawkを使っています。
    また、GO32.EXEというDOSエクステンダも併用しています。
    例として、C:ドライブにインストールしている場合の設定を示します。

    SET GCC_EXEC_PREFIX=C:\SATURN\GCCSH\LIB
    SET C_INCLUDE_PATH=C:\SATURN\GCCSH\INCLUDE
    SET INFOPATH=C:\SATURN\GCCSH\INFO
    SET CPLUS_INCLUDE_PATH=C:\SATURN\GCCSH\INCLUDE\CXX;C:\SATURN\GCCSH\INCLUDE
    SET GO32=2r1
    SET TMPDIR=C:\TMP
    SET AWKENV=C:\SATURN\AWK

    GO32 という環境変数は、DOSエクステンダの動作を制御します。
    この環境変数に 2r1 を設定すると、標準エラー出力が 標準出力に変更されます。
    変更したくない場合は、この環境変数に何も設定しないで下さい。

    Windows95使用時ではDOSプロンプトのプロパティ中、バッチファイルという
    項目があります。  ここに上記の環境変数の設定を行うバッチファイルを指
    定すれば、 DOSプロンプト起動時に自動的に設定されます。
    PC起動時に、AUTOEXEC.BAT 内で設定してもどちらでも構いません。
