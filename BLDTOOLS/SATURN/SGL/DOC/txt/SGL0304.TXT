●SGL Ver. 3.04 リリースノート
                                                     SEGA Technical Support
                                                     1997/4/12 N.T
                                                     1997/4/17 N.T修正


◎追加された機能／関数
  なし。

◎変更点
  １）SGL関数のバグ修正。
      slDispSpriteSZ()   :この関数をコールした後の関数コールでハングアップ
                          するバグを修正。

  ２）サンプルプログラムの修正。
      saturn/sgl/sample/sys :このサンプルのリンクファイルでのファイルリンクの
                             順番に問題があり、このサンプルを使って作成された
                             IPが正常に動作しませんでした。
                             SGL Ver. 2.xの時には問題ありませんでしたが、
                             SGL Ver. 3.xのものをお使いで且つ同様の症状が
                             出る場合それが原因と考えられますので、差し替える
                             様お願い致します。
      saturn/sgl/sample/sbklib :このサンプルでのバックアップ関数の作業領域
              SGIの場合         確保の仕方に問題がありました。これまで、
                  sampBkLib     作業領域をバックアップ関連のイニシャライズを
                                行なう関数「BackUpInit」のローカル変数として
                                確保していましたが、この方法は、BackUpInit関数
                                を抜けた後の作業領域のデータの信頼性に著しく
                                問題があるため、グローバル変数としました。
                                他の方法としては、作業領域をローカル変数として
                                とる代わりに、全てのバックアップ操作をその
                                関数内で完全に終らせる。という方法もあります。
                                この場合、その関数から他の関数を呼ぶ分には
                                問題ありません。

  ３）slWindowの仕様変更
      slWindowで定義されるZリミットに関して、今まで0x0000から0x7FFFの範囲から
      0x0000から0x1FFFの間に仕様変更をしました。
      もしそれ以上の値を代入しても0x1FFFに補正されます
      (注意)
       いままで初期値が0x7fffでしたが0x1fffになっています。
       表示される範囲が変わっているので表示に関しては注意してください。

  ４）slSetSprTVModeのバグ修正
      この設定を行うと強制的にVDP1がパレットモードになってしまうという症状を
      修正しました。
      設定する画面サイズによってモードが変わります。
      但し、この症状は後で、
      slSpriteColMode [scroll]
      を使って明示的に処理する事で回避できます。

  ５）PCMライブラリのバージョンアップ。
      SBLのバージョンアップに合わせて、PCM・ADPCM再生ライブラリの最新版
      ( Ver. 1.22 )を提供します。

注意すべき点）
  スプライトとポリゴンのソートを行なう際にスプライト描画関数に与える、
  Z基準値は、ポリゴンのZポジションと同等に扱うことは出来ません。
  スプライト描画関数で与えるZ基準値とZソート値との相関関係は以下の式で表され
  ます。
  (Zソート値) = (Z基準値) - (視点からスクリーンまでの距離) / 2
  (視点からスクリーンまでの距離)は、SGLのシステム変数、
  MsScreenDistで与えられますので、例えばスプライトの描画用に与えるZ基準値は、

  extern FIXED MsScreenDist

  #define Z_BASE    toFIXED( 150.0 )
  #define Z_SORT    Z_BASE - MsScreenDist / 2
                   :
  slPushMatrix();
  {
    slTranslate( toFIXED( 0.0 ), toFIXED( 0.0 ), Z_SORT );
    slPutSprite( ... );
  }
  slPopMatrix();

  の様にする事で、Z_BASEの値をポリゴンのZソート値と同等な様に扱う事が出来ます。

※前回お配りしたSGL Ver. 3.04のPCM・ADPCM再生ライブラリで、Saturn PCMを使用
  すると、シンボル定義されていないといったエラーが出力されます。
  これは、こちらでライブラリ作成時に一部のファイルをリンクし忘れた為に、
  起こった現象です。今回提供のバージョンでは改善されていますので、そちらを
  お使い下さい。
  御迷惑をおかけしまして大変申し訳御座いませんでした。
