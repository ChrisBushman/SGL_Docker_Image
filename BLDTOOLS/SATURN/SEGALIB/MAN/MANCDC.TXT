１．３　処理内容の変更

（１）　内部構造の見直し
　パフォーマンス向上のため内部構造を見直し、プログラムサイズを縮小しまし
た。

２．　MPEGパートの組み込み
　CDC Ver.1.20からMPEGパートの機能が正式に組み込まれています。仕様につい
ては、CD通信インタフェースマニュアルのMPEGパートを参照して下さい。

※おわび
　MPEGパートの画面特殊効果パラメータに関連して、用語「モザイク」の綴りに
誤りがありました。正しくは、MOZAIC → MOSAIC です。
　修正しようとすると、CDCとMPEGライブラリの外部シンボル内にも使われており、
影響が大きくなります。従って、修正はせずに現状のままとします。
　ご迷惑をお掛けして申し訳ありませんでした。

３．　SCU-DMA使用時の注意事項
　SCU-DMA転送中はA-Busアクセス禁止のため、全てのCDC関数の使用を禁止します。
　詳細は次の文書を参照してください。
　・Developer's Information STN-10「SCU仕様変更による制限事項・注意事項」
　　No.08「A-Bus ←→ B-BusのDMA動作中のCPUからのA-Bus, B-Busへのアクセス
　　　　　禁止」

５．　補足説明

５．１　頻繁なseekを伴うCD再生時の注意事項 (1997-07-03 追加)
５．１．１．概要
	CDドライブのシーク・データ出力までに要する時間は、ドライブの経年変化や
	game discの汚れ、傷によっても増加します。
	Gameデータの作成上、graphic data fileとsound data fileを別々に用意し、
	交互にシーク、リードを行う場合があります。こういった作成方法を行った
	時のCD制御方式について注意すべき点を以下に述べます。

５．１．２．症状
	graphic data取得後、sound dataを取得し、これを繰り返す様なprogramを
	作成する場合に音途切れを回避するため一定間隔で強制的に音声データの
	取得を行うように組んでしまった場合には、音声データ取得の直前の
	graphic dataの取得が完了する前に、音声データ取得を実行してしまう可能性
	があります。
	その結果、graphic dataの取得エラーが発生しリトライをしてしまう、という
	現象が発生します。
	また別の現象として、シークコマンドが短時間に連続して発行された場合（
	ホストから発行されたシークコマンドをＣＤブロック側で処理中に、さらに
	ホストからシークコマンドが発行された場合）には、通常シークに要する時間
	よりも大幅に処理時間がかかる事があります。(ＣＤブロック仕様)

５．１．３．対策
	５．１．２項の状況を回避するためには、以下の対策を検討して下さい。
	・頻繁にアクセスされる２つ以上のfileは、CD上の物理的配置がなるべく近く
	  なるようにして下さい。物理的な配置の順番は、ＣＤスクリプト上での記述
	  の順番と同じくなります。(ただし同ディレクトリ内での記述) FAT上の順番(
	  file name順になる)とは関係ありません。
	・各種データの取得のためにfileをアクセスする時に、前回の読み込み(CDドラ
	  イブからSH1の中のbufferへの読み込み)が完了しているか否か調査し、完了
	  後に次のデータ取得を発行するようにしてください。
	 このためには、以下の様なチェックシーケンスを、データ取得コマンド発行の
	 前に行うようにして下さい。

	    CdcRet  ret;
	    CdcStat stat;
	    Uint8   nowstat;

	    ret = CDC_GetPeriStat(&stat);   /* 現在のドライブステータスの取得  */
	    if (CDC_RET_ERR(ret) != CDC_ERR_OK) {
	        continue;
	    }
	    nowstat = (CDC_STAT_STATUS(&stat) & 0x0F);  /* 現在のステータス */
	      /* これでnowstatに現在のドライブステータスが取得されました */

	    if ((nowstat == CDC_ST_PAUSE) || (nowstat == CDC_ST_STANDBY)) {
	      /* CDドライブがpause、standbyの時にここにきます。         */
	      /* 次のデータ取得コマンドを発行しても問題ありません。     */
	    }
	    else {
	    /* CDドライブがpause、standby以外の時にここにきます。               */
	    /* ここでさらに、nowstatをチェックすれば、詳細が判ります。          */
	    /* もし、nowstat == CDC_ST_SEEKであったり、nowstat == CDC_ST_PLAYで */
	    /* あったり、nowstat == CDC_ST_BUSYであった場合以前のデータ取得が   */
	    /* 完了していない訳ですから、この時に次のデータ取得を発行しては     */
	    /* いけません。                                                     */
	    /* この場合の処理は、gameによって異なります。                       */
	    /* nowstat == CDC_ST_PAUSEになるまで、３秒位のタイムアウト待ちと    */
	    /* する、他の(CDドライブに関係の無い)処理を行う、又は、             */
	    /* 一度 ポーズコマンドを発行し、強制的にリード・シークを打ち切る    */
	    /* 等が考えられます。                                               */
	    }


６．　変更履歴

６．１　Ver.1.20からVer.1.21への変更点（1996-12-28）
　CPU内部除算器使用時の割り込みマスク処理に関する不具合対応のために、ライ

６．２　Ver.1.21からVer.1.22への変更点（1997-02-27）

（１）　定数名の修正
　MPEGパートの透明ビットモードを以下のように修正しました。

　/* 透明ビットモード（画面特殊効果パラメータ内） */
　・CDC_MPTRP_128　→　CDC_MPTRP_96        0x02    /* 輝度96 */
　・CDC_MPTRP_256　→　CDC_MPTRP_128       0x03    /* 輝度128 */

（２）　SHCコンパイラバージョンとコンパイルオプションの変更
　コンパイルオプションを以下のように変更しました。
　　-div=peri ：除算機を使用（割り込みマスクあり）
　　-macsave=0：関数呼びだしでMACH, MACLレジスタを保証しない

　※コンパイラのバージョンは必ずSHC Ver.3.0G以降を使用して下さい。
