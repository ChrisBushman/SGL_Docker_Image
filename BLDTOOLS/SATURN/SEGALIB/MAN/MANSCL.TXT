1.変更履歴
  1.1. Ver.1.22からVer.1.23への変更点
       a)CPU内部除算器使用時の割り込みマスク処理に関する不具合対応のために
         ライブラリのコンパイルオプションを-div=cpuとしました。

  1.2. Ver.1.21からVer.1.22への変更点
     a)NBG0とNBG1で同時にラインスクロールを使用できない不具合を、修正しました。
       修正したのは、'SCL_FU05.C'の、SCL_SetLineParam()関数です。
     b)SH C版のコンパイルオプションを、'-div=nomask'から'-div=peripheral'に
       変更しました。

  1.3. Ver.1.20からVer.1.21への変更点
     SclRotateTableAddress()へ何も値を設定しない場合、不正な番地へのライト
     動作が起こる不具合を修正しました。

  1.4. Ver.1.04からVer.1.20の変更点
     a)VDP1ライブラリVer.1.20のバージョンアップによる改良
       VDP1ライブラリ作成時にSPR_SYNC_VB_OUTを定義している場合(デフォルト状態)
       SCL_DisplayFrame() のスプライトのフレームバッファ切り替え待ちがＶブラン
       クアウトになり、１フィールドの処理時間が延びます。
       スクロールのレジスタ書き込みは、SCL_DisplayFrame() を待たずＶブランク
       インで行われます。
       VDP1ライブラリ作成時にこの定義をコメントアウトすると、従来通りＶブランク
       インでスクロール、スプライトの同期が取られます。
       変更したファイルは、SCL_VBLV.Cです。
     b)SCL_SetColOffset関数のバック画面対応
       バック画面に対してカラーオフセット機能を使用できるように対応しました。
       変更したファイルは、SCL_PRI12.Cです。

2. 変更に伴う仕様の変更について
     2.1. 2ndステップライブラリ(Ver.0.90)との違い
       a)基本的には、ソースコードレベルで互換です。リコンパイルにより
         2ndステップで作成したアプリケーションがそのまま動作します。
         ただし、以下の場合には注意が必要です。
         ・テーブル初期化関数を使用していない場合
          ［対策］新たに追加されたテーブル項目についても初期化をする。
         ・memcpyw()を使用されている場合
          ［対策］ファンクション名をSCL_Memcpyw()に変更して下さい。
                  レジスタやカラーRAMなどのByte転送不可以外の領域であれば、
                  標準関数のmemcpy()と置き換えることも可能です。

       b)新たに追加された5つの関数
        ・SCL_SetRotateCenterDisp()
          回転スクロール面を画面回転させる場合の中心点を設定
        ・SCL_SetCoefficientData()
          回転パラメータ係数テーブルに拡大縮小データをセットする
        ・SCL_DisableBlur()
          ボカシ演算を無効にする
        ・SCL_DisableLineCol()
          ラインカラー画面を解除する
         ・SCL_AbortAutoVe()
          自動VEの強制終了

       c)回転面のZ軸方向移動の仕様の変更
         回転角度0度でもZ座標の指定が有効になりました。
        （回転角度0度で値を変化させた場合は、みかけ上拡大縮小と
          変わりません。）

       d)回転パラメータ係数テーブルをカラーRAMに設定できるようになりました。
         V-RAMコンフィグレーションデータの構造体に1項目追加されました。

       e)回転パラメータ係数テーブルの設定位置を0x400単位で指定できる
         ようにしました。
         VRAMコンフィグレーションデータの構造体に２項目追加されました。

       f)スクロールで１ワードパターンネームデータを使用する場合の
         ・不具合を修正しました。2ndSTEP版では、V-RAMの後半にキャラクタ
         パターンデータを配置できないという不具合がありましたがこれを
         修正しました。
         ・スクロールコンフィグレーションデータの構造体に1項目
           追加されました。

       g)実行型ファイルを小さくする為、ライブラリソースファイルを
         細分しました。内部で使用している三角関数のsin(90),cos(0)が
         1.0ではありませんでしたがこれを1.0に修正しました。

  2.2. 3rdSTEPライブラリ(Ver.1.00)との違い

       a)SCL_SetAutoColMix()のバグ修正

       b)SCL_VblankEnd()のバグ修正

  2.3. 3rdSTEPライブラリ(Ver.1.02)との違い

       a)SCL_SetConfig()のバグ修正
         回転スクロール面の設定に誤りがありました。
        （画面オーバー処理とプレーンサイズ）

       b)X軸回転とY軸回転の時に最後のラインにごみがでるバグを修正。

  2.4. 3rdSTEPライブラリ(Ver.1.03)との違い

       a) コンパイル時にファイル名を大文字で指定していたのを小文字に変更。

       b) SCL_SetFrameInterval()のイレースライト指定の設定が正しく
          行われないバグを修正。

       c)SCL_AllocColRam()で256色以上の領域を確保できないバグを修正。

       d)ラインスクロールが処理落ちするバグを修正。

 2.5. ライブラリの改造について
      3rdSTEPでは、ライブラリの機能強化や高速化などカスタマイズを
      容易するため、スクロールライブラリのレジスタバッファをマニュアルに
      記述しました。簡単な機能追加方法を解説します。

      a)画面表示ON/OFF （全画面の表示ON/OFFの指定）
       ［画面ON］
        void disp_on()
        {
                Scl_s_reg.tvmode |= 0x8000;
                SclProcess = 1;
                SCL_DisplayFrame();/* フレームチェンジがオート以外の場合 */
        }
       ［画面OFF］
        void disp_off()
        {
                Scl_s_reg.tvmode &= 0x7fff;
                SclProcess = 1;
                SCL_DisplayFrame();/* フレームチェンジがオート以外の場合 */
        }

     b)他の機能は使用せずノーマルスクロール面0(NBG0) のX座標だけを
       変化させたい場合

      ［どこでも可］
        Scl_n_reg.n0_move_x = ???;（スクロール座標の指定）
      ［V-Blank In割り込み内］
        (*(Uint16 *)(0x25f80070)) = Scl_n_reg.n0_move_x;
