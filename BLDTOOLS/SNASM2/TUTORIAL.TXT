

            Basic C++ tutorial for C++ debugging using snbugsat
            ---------------------------------------------------
                    Author G. Ellison (Cross Products LTD.)


Introduction
------------

The tutorial is aimed at introducing the C++ support feature provided by
the snasm development tools.  The example is a simple program that creates
a base class which stores the position of an object & a derived class that
supports the display a text string.

The program bounces the string "Hello world" around the screen and
displays it co-ordinates in the log window using libCross fileserver
support.


Contents
--------

The example consists of four file

  TUTORIAL.TXT - This readme file.
  MAKEFILE     - Very basic makefile (require customisation to correct
                                      library/ gnu directories)
  EXAMP.CPP    - The test program
  SL.COF       - Pre-compiled cof


Requirements
------------

The example was developed for use with SNBUGSAT ver 2.10f or greater, and
gnu & sega (SGL 1.31) from the Novemeber 95 DTS disk.  Ver 2.10f fixes
several bug encountered when upgrading to the new compiler.


Notation
--------

In the example

   Format           Operation
   ------           ---------

   >                key strokes entered
   ORIGIN->GOTO     menus selected
   [F4]             function key [f4] pressed
   * <text>         displayed text


Example
-------

STAGE - 1 display a class
-------------------------

Load the example cof into the dubbuger

  > snbugsat -t1:sl.cof

Open a mixed window

  WINDOW->MIXED

Displays the window with the line under

  * 'SGL_Start'

highlighted.  Move the screen origin to the main() routine using

  ORIGIN->GOTO
  > main

Move down the main() routine, by selectin the source region (top half) of
the mixed window & then scrolling down using the down arrow.  Stop with
the cursor on the line

  * 'slInitSystem(TV_320x224, NULL, 1);'

Run to this point by selecting

  [F6]

This will produce a '<*>' on the selected line showing the position of
the PC.  Open a watch window

  WINDOW->WATCH

and add a request for the variable 'base'

  EDIT->ADD
  > base

This will display

  * '+ struct BaseClass {...} *base (r10) 0x0600d404'

to expand this struct select it with the mouse, and the screen will display

  * '- struct BaseClass {...} *base (r8) 0x0600d404'
  * '  + struct BaseClass {...} @ 0x0600d404'

select the newly displayed element and the contents on base will be
displayed, as shown below.  Note that the class is displayed based on the
pointer type 'BaseClass' & note the actual element type 'DerClass'.

  * '- struct BaseClass {...} *base (r8)0x0600d404'
  * '  - struct BaseClass {...} @ 0x0600d404'
  * '    int m_nXInc = 1'
  * '    int m_nYInc = 0'
  * '    int m_nXPos = 1'
  * '    int m_nYPos = 1'
  * '    int m_nOldXPos = 1'
  * '    int m_nOldYPos = 1'
  * '    float m_fAngle = 100.01'
  * '    + struct "Not Available" {...} (*$vf)[3] = 0x060042bc'

note: The last element is a pointer to the virtual table used during
runtine.

Stage 2 - Examine a member function
-----------------------------------

Minimise the watch window by selecting the down icon in the top right of
the window.  Select the mixed window (source region).

To move to a member function, select

  ORIGIN->GOTO

enter below into the expression

  > Der

and select symbol complete [ALT-S], this will give you the following list

  * 'DerClass'
  * 'DerClass::DerClass'
  * 'DerClass::Display'
  * 'DerClass::~DerClass'

select the DerClass::Display() member function & select OK twice.
The mixed window will highlight the '{' under the function definition.

Scroll down the display function placing the cursor on the line

  * 'BaseClass::Display();'

Run to this point by selecting [F6]. The log window will appear showing
the message 'Hello World'

To view the contents of the 'this' pointer select

  WINDOW->LOCAL VARS

A watch window will appear showing the following information

  * '+ struct DerClass {...} *this (R8) @0x0600d404'

This class can be expanded in a similat way to that in the STAGE 1, revealing
two elements.  The base class & the additional string.

  * '- struct DerClass {...} *this (r8) 0x0600d404'
  * '  - struct DerClass {...} 0x0600d404'
  * '    + struct BaseClass {...} BaseClass 0x0600d404'
  * '    + char *m_spzName = 0x0600e004 -> "Hello World"
