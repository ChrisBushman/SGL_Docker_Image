   1.1.1. サンプルデータの不良対策

     1994-11-11提供のsmpsnd1では、シーケンスデータを発音できない不良が

     と変更ファイルを示します。
     (サウンドドライバの仕様変更についてはsaturn/segadrv/manのドキュメント
     を参照してください。）

        smpsnd1データファイル一覧       変更ファイル

        boottone.bin    音色
        bootse.bnk  シーケンス              ○
        pitch.bnk   シーケンス              ○
        bootse.exb  DSPプログラム
        vc_ps.exb   DSPプログラム
        surround.exb    DSPプログラム
        3bandana.exb    DSPプログラム
        bootsnd.mp  エリアマップ            ○

        　ため変更しました。以下にbootsnd.mp内のシーケンスデータサイズ変更点
        　を示します。

    1.1.3.補足説明

            ・サウンドメモリへのアクセスについて
              サウンドメモリへ頻繁にアクセスすることを禁止します。ホスト側(SH)
              からサウンドメモリへ頻繁にアクセスすると、そのメモリはサウンド
              ドライバが見ることができないため、サウンドドライバが動作しなく
              なります。

             （例）SND_StartSeq(1,0,0,0);
                while(SND_SEQ_STAT_MODE(status) == SND_MD_STOP){
                    SND_GetSeqStat(&status, 0);
                }

                上記の場合，永久ループしてしまう可能性があります。理由はホスト
                側がステータスのメモリを頻繁にアクセスするため、シーケンスが終
                了してもサウンドドライバがSTOPのシーケンスをステータスのメモリ
                へ書き込めないためです。

            ・注意
              1)1994-08-22提供のサンプルSMPSND3.C について
                このサンプルを削除します。理由はこのサンプルで使用している
                割込みステータスレジスタがSCUの制限事項のため使用できなく
                なったためです。

              2)サンプルプログラムのPCMデータについて
                smpsnd4とsmpsnd5に使用しているPCMデータ音を聞くと，おかしな
                曲に聞こえます。ハードウェア、及びソフトウェアの不具合では
                ありません。PCMデータがおかしいためです．ご了承ください．

		  ・サウンドドライバに対するコマンド発行プロセスの管理方法を、

		  ・サウンドドライバ Ver.2.20 の PCMスタートコマンドの仕様変更
		    (トータルレベルの指定パラメータ追加)に対応しました。
		1.6.2. ライブラリ追加事項
		  ・SndPcmChgPrm構造体に、トータルレベルを設定する変数を追加しました。
		    設定可能な範囲は、0～255 です。
		    		0:最大音量 ～ 255:最大減衰(-95.7dB)
		  ・上記追加変数へのアクセスマクロを追加しました。
			追加マクロ SND_PRM_TL(SndPcmChgPrm* )
				(使用例)
					SndPcmChgPrm *cprm;
					SND_PRM_TL(*cprm) = 0;  /* トータルレベルを 0に設定 */
		1.6.3. 補足説明
		  ・トータルレベルについて
		  		PCM再生時に指定が可能なトータルレベルは、減衰率で指定します。
		    		0:最大音量 ～ 255:最大減衰(-95.7dB)
		  		この指定は、ダイレクトレベルおよびミキサー入力レベルの前段階
		  		で反映される為、両方の音量に影響します。
				ハードウェア的に対応するのは、SCSPのスロット別音量レジスタの
				TLです。

		1.7.3. 仕様変更
			Ver.1.30 では、PCM再生におけるトータルレベルへの対応により、
			PCM再生において従来のアプリケーションとのソースレベルの互換性が
			ありませんでした。(トータルレベルの設定が不定となってしまう)
			本バージョンでは、ソースレベルの互換性を取る様に修正を
			行いました。(トータルレベルを強制的に 0 にします)
			トータルレベルの指定を有効にするには、本バージョンで追加
			した関数を使用して下さい。

		1.7.4. SGL対応版
			サウンドＣＰＵの停止/起動に、SMPCコマンドの発行を行っていますが、
			このコマンド発行を SGLの関数を使用する様に変更しました。
			SGLユーザは、SGLと同時に配布される LIBSND.A を必ず使用する様に
			して下さい。

		1.7.5. ヘッダファイルの統一
			ライブラリコンパイル時に使用していた SND_MAIN.H を削除し、
			SEGA_SND.H に統一しました。
			また、SBLとSGLのヘッダ統一にあたり、SGLユーザは SGL V.3.20以降を
			使用する必要があります。(SL_DEF.H 等に変更があります。)
