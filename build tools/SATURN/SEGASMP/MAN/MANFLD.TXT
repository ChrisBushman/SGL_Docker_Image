1.サンプルの動作内容と使用方法
    ●smpfld01.c
        [タイトル]  ファイルローダサンプル
        [動作内容]  ファイルローダの関数を使用しアプリケーションの起動を行います。
        [使用方法]
                    (1)  以下のディレクトリ構成のディスクを作成する。
                        \:
                         | FLD_KNL.BIN        ;ファイルローダのカーネル
                         |
                         | SAMP_IP.BIN        ;アプリケーションのIP
                         |
                         | SAMP :             ;SAMPディレクトリ
                                |
                                | 0           ;アプリケーションの1stリード
                                               ファイル
                    (2) 以下のコマンドでブートＲＯＭを初期化。
                         RS [RET]
                         GO [RET]
                         [CTRL-C]
                         GO 400[RET]
                         [CTRL-C]
                    (3) smpfld01.abs を 6010000H 番地にロードし、
                        GO 6010000 [RET] で実行。

        [使用ファンクション]
                    ●FLD_ExecGame()
