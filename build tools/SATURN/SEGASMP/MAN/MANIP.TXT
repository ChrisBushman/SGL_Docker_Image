ＦＡＱ：
Q1:サターンが ゲームＣＤとして認識しない。
A1:メーカーID と、エリアコードを確認して下さい。
    → SYS_ID.SRC ： メーカーＩＤ、エリアシンボル( JTUE )
       SHLNK.SUB ：エリアコード( SHC環境 )  SYS_AREx.OBJ の種類
       SAMPLE.CFG：エリアコード( GNU環境 )  SYS_AREx.O の種類

Q2:起動途中(ＳＥＧＡロゴ表示中)に、ハングします。
A2:1stREAD アドレスと、プログラムのジャンプ先を確認して下さい。
    → SYS_ID.SRC ：1stREAD アドレス
       SMPSYS.C ：APP_ENTRY の define内容

Q3:IP に関するマニュアルは、どこを参照すれば良いのでしょう？
A3:プログラマーズガイドの、「DISKフォーマット規格仕様書」の、
   「４．ブートシステム」の項を参照して下さい。

Q4:メーカーＩＤ、製品コード等は、どこに聞けば良いのでしょう？
A4:SEGA営業担当者 → 販売会社の担当者 → 開発会社 → ．．．
   の順に情報が流れますので、さかのぼってください。

Q5:バージョン番号に関する規定はありますか？
A5:特に規定はありませんが、最初のマスター提出バージョンを 1.00 の
   基準にして下さい。
   以降、改変の度に数字を上げて下さい。



Ver.1.10以前からの内容
(1) [smpsys.c] について

　サンプルのアプリケーション初期化プログラム [smpsys.c] は、このバージョンから
Ｃ言語記述になりました。古い [smpsys.src] は不要になります。

　[smpsys.c] には、初期化処理として、ＶＤＰなどのメモリクリアや、デバイスを
初期化するサンプル処理ルーチンが含められました。これはアプリケーション起動時、
起動前のＣＤマルチプレーヤのパネルなど、消え残ってしまったグラフィックが、
一瞬表示されるバグなどを防止します。

　[smpsys.c] の実行時間は、約０.１秒です。ライセンス表示中に実行され、この
表示時間がその分延ばされます。より有効な処理を行なうには、アプリケーションで
ソース上の不要な処理を削除し、必要な処理を追加してカスタマイズしてください。


(2) [smpsys.c] のカスタマイズについて

　例えば、ＶＤＰなどのメモリクリア処理は、前処理として、アプリケーション起動時
のメモリ残留データの消去を行なうものです。しかし、クロック切替えを行なわない
ならば、アプリケーション用データ書込みを行なうほうがより有効です。

　また例えば、もし ２６Ｍ→２８ＭＨｚ システムクロック切替えを行なう場合、
ＶＤＰ１、ＶＤＰ２、ＳＣＳＰ などのレジスタ設定や、ワークＲＡＭ(Ｈ)以外は、
切替えまでの間のみ有効であり、切替え後再設定が必要なため、後で間に合う処理は
後回しにするべきです。


(3) [..\segalib\lib\sys_init.obj] について

　[sys_init.obj] は ８０Ｈ バイトのオブジェクトで、システムワーク領域を初期化
します。ＩＰ内のエリアコード直後に配置してください。新しいリンクバッチ
ファイル [smpsys.lnk] は、このリンケージ情報を含んでいます。


(4) 1stリードファイルのロード指定範囲について

　1stリードファイルの読込みが可能な範囲は、ワークＲＡＭ(ＬまたはＨ)の
４バイト境界としてください。アドレスでは、２０００００Ｈ～２ＦＦＦＦＣＨ、
または、６００２０００Ｈ＋ＩＰサイズ ～ ６０ＦＥＦＦＣＨです。
注：６０ＦＦ０００～６０ＦＦＦＦＦまではシステムが使用している為、1stREAD
    ファイルを読み込む事を禁止します．
    IP実行後ユーザに開放されますので、ユーザアプリケーションに制御が移った後は、
    使用可能となります．


(5) その他の変更について

　システムＩＤ仕様は 94-08-22 版と同じです。ただし、サンプルＩＰのサイズが
増えたため、サイズの記述内容が変更になっています。
なお、コンパイラのバージョン等によって、実行バイナリのサイズは変化しますので、
必ずサイズを確認して下さい。

　ＣＤ (またはエミュレーション)に使用の場合、サイズの記述は、実際のＩＰファイル
サイズより大きめで、１０００Ｈ～８０００Ｈであれば、問題ありません。
ただし、ロード領域が十分に確保されていることが必要です。

　添付の [ip.bin] のシステムＩＤの記述はＣＤ用です。カートリッジＩＰとして
使用するには、[sys_id.src] を修正し再作成する必要があります。


(6) GNU環境でのコンパイルについて
  SYS_ID.SRC は、日立アセンブラの文法にて記述されており、そのままではGNUアセ
ブラでアセンブルできません．
  本サンプルでは、awkを使用することでGNUアセンブラの文法に変換してからアセン
ブルしています。
  awkについての説明は、SATURN\AWK ディレクトリに入っているドキュメントファイル
(README.TXT) を参照してください。


(7)独自にカスタマイズする際の注意点
  smpsys.c を改造して使用する場合、main()の前に実行文を含む関数を、追加しない
で下さい。

       Ver.1.31  1997-08-29 A.H
                 DATEL社製 未承認カートリッジのチェック機能を
                 追加(デフォルトはチェックしない)

                 厳守事項：
                    本機能はテスト用に追加したものである。
                    動作不具合、ユーザクレームその他に関する対処については、
                    使用者の責任において対応する事。

                 目的：エリアプロテクトを強化したい
                       セガ未承認のカートリッジ型 解析ツール等の有無を
                       判別したい。

                 具体例  ：通常は本体 BOOT-ROM内のエリアプロテクト機構が
                           働くが、セガ未承認の
                           「エリアプロテクト解除カートリッジ」
                           を使用された場合は、エリア外の本体でも起動して
                           しまう。

                 使用方法：
                        smpsys.c 内にて 
                        USE_CHKOUT_DATEL_CART を define する事。

                 使用結果：
                        DATEL社製 「UNIVERSAL ADAPTER」がカートリッジ
                        端子に接続中の場合は、ゲームの起動を中止し、
                        マルチプレイヤを起動する。
                        なお、IPサイズに注意する事。

                 動作原理：
                        エリアプロテクト解除ツールは、A-BUS接続の自己
                        起動するカートリッジである。
                        よって該当アドレスのメモリ内容をチェックすれば、
                        これらカートリッジの接続の有無を確認可能である。

                 詳細：
                        自己起動するカートリッジは、絶対アドレスの
                        0x02000000～0x0200000F までにアスキーコードにて
                        「SEGA SEGASATURN 」と識別コードが入っている。
                        このようなカートリッジは、正規の既発売ペリフェラル
                        には存在しない。
                        よって、0x02000000～0x0200000F までのメモリ内容を
                        チェックし、問題のカートリッジの接続有無をチェック
                        する事が出来る。

                 注意事項：
                        今後、自己起動するサターン用カートリッジが正規の
                        ペリフェラルとして発売された場合、そのカートリッジも
                        チェック対象となってしまう。
                        よって、チェック対象を問題のカートリッジにしぼりこむ
                        為には、チェックする範囲を広範囲にするべきである。
