1.サンプルの動作内容と使用方法
    ●"SEGASMP\PER\smpper0"(main.c)
        [タイトル]  ペリフェラルコントロール系、システムコントロール取得系
                    サンプル
        [動作内容]  ゲーム実行中のコネクタに接続しているペリフェラルを変更する
                    と、そのペリフェラルIDを判断し、それぞれのアドレスに値を書
                    き込みます。

                    ペリフェラルデータ、タイムデータ、システムデータを取得します。
                    以下に書き込みアドレスを示します。

                        0x6040000 システムデータ
                        0x6040020 ペリフェラルデータ
                        0x6040030 タイムデータ

                    ペリフェラルデータ取得の設定は以下のとおりです。

                        種別：  デジタルデバイス
                        取得数：2

        [使用方法]
                   以下は、E7000 ICE時のコマンドです。
                    (1) 以下のコマンドでブートＲＯＭを初期化。
                         RS [RET]
                         GO [RET]
                         [CTRL-C]
                    (2) smpper0.abs を 6002000H 番地にロードし、
                        GO 6002000 [RET] で実行。
                    (3)接続ペリフェラルのボタンを任意に押してください。
                    (4)途中で、各コネクタの接続ペリフェラルを交換しても正しく
                        、情報を書き込みます。

        [使用ファンクション]
                    ●PER_Init()
                    ●PER_GetPer()
                    ●PER_GET_TIM()
                    ●PER_GET_SYS()
                    
    ●"SEGASMP\PER\smpper1"(main.c)
        [タイトル]  システムマネージメント系サンプル
        [動作内容]  SMPCのシステムマネージメント系のコマンドを実行します。

        *(Uint32 *)0x6050000に実行したいコマンドの番号を入力してください。又、
        コマンドに入力が必要な場合は、*(Uint8 *)0x6050030から入力してください。

           コマンド番号 -> *(Uint32 *)0x6050000
           入力         -> *(Uint32 *)0x6050030

           +---------------------------------------+
           |コマンド番号    コマンド名称           |
           +---------------------------------------+
           |        0x02    スレーブSH2 ON         |
           |        0x03    スレーブSH2 OFF        |
           |        0x04    サウンドON             |
           |        0x05    サウンドOFF            |
           |        0x09    NMIリクエスト          |
           |        0x0a    ホットリセットENA      |
           |        0x0b    ホットリセットDIS      |
           |        0x0c    SMPCメモリ設定         |
           |        0x0d    時刻設定               |
           +---------------------------------------+
           
           
        [使用方法]  (1) 以下のコマンドでブートＲＯＭを初期化。
                         RS [RET]
                         GO [RET]
                         [CTRL-C]
                    (2) 実行ファイル を 6002000H 番地にロードし、
                        GO 6002000 [RET] で実行。

        [使用ファンクション]
                    ●全部

    【備考】
     上記の実行方法は日立のＩＣＥ環境でのものなので、ターゲットがカートデブ
     の場合などはそれぞれの環境に応じた方法で実行して下さい。
