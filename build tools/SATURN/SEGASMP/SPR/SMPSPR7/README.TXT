1997-09-01  ＳＥＧＡ テクニカルサポート

本サンプルの実行ファイルの作成には、3D処理をサポートした SEGA_SPR
ライブラリが必要です。

SEGA_SPRライブラリは Ver.1.24 から 3D処理が未サポートとなった為、
そのままリンクした場合、正常な実行ファイルを作成出来ません。
3D処理をサポートした SEGA_SPRライブラリのソースは、
 SATURN\SEGALIB\SPR3 フォルダ
に収録していますので、ライブラリをリコンパイルしてご使用ください。

ただし、上記フォルダに収録した SEGA_SPRライブラリは、スレーブSH2,
SCU-DSP を使用します。
その他のライブラリやアプリケーション側とのハードウェア資源の競合
には十分ご注意ください。

以上。
