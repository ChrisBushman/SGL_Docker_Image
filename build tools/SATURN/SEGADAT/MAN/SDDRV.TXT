□変更履歴　　サウンドテクニカルチーム

;=======================================================
;	ver-2.01 への履歴
;=======================================================

● DSPLFOを削除。

● 連続リクエストでもダンパーがクリアされるようにした。一旦演奏を止めてから
   次の曲をリクエストすればクリアされるので、決してバグではない。

● Pauseをかけると発音管理番号によってはプログラムが暴走することがあるという
   致命的なバグを修正。ちなみに発音管理番号０のときには起こらない。
   すいません。チェックがあまかったようです。

● モノモードにしたとき、サウンドシミュレータに対してエラーを返すようにした
   (138)。

● タイミングフラグがoff、同じリクエストバッファ、なおかつコマンド処理中の
   ときにつぎのリクエストが入ってくると処理終了後にそのコマンドコードを消し
   てしまい、リクエストが受理されないことが希にあることを発見。
   SH2がかなり高速なためこの症状を完全に防ぐことはできないが、ある程度改善
   した。エラーも返すようにした。まあ、普通はタイミングフラグを使うので問題
   ないとは思う。

;=======================================================
;	ver-2.02 への履歴
;=======================================================

● note onルーチンを高速化。いわゆる「曲がもたる」といったことはまず起こら
   ないでしょう。

● 発音管理番号０以外でフェードのかかり具合がおかしいというバグを修正。
   すいません。チェックがあまかったようです。

● ホストコマンドからsequence panを送ったとき、ストリーム再生中だとそちらの
   panにもに影響してしまうというバグを修正。

;=======================================================
;	ver-2.03 への履歴
;=======================================================

● note on中にdirect panを送っても反応しないというバグ（ver-1.30あたりから
   のもの）を修正。

● seq startの直前にmaster volumeをセットしてもまったく効いていなかったこと
   が判明。ソフトウェアライブラリによるサウンドコールでは致命的。

;=======================================================
;	ver-2.04 への履歴
;=======================================================

● PEGがおかしいという積年のバグを修正…したつもりだったが、改善されず。

;=======================================================
;	ver-2.05への履歴
;=======================================================

●SCSPにリリースの終了を返すレジスタが存在するという情報を入手。本バージョン
  はNOTE OFFではなくリリース終了でスロットの開放を行なうようにしようとした実
  験版です。結果は、処理速度が低下したためボツとなりましたので、ネクストバー
  ジョンは2.04からのバージョンアップとなります。

;=======================================================
;	ver-2.06 への履歴
;=======================================================

●フェード中にsequence stopを発行するとモードステータスの表示が「２」になっ
  たままであるというバグを修正。

●「tempo change」ルーチンを挿入。

●シーケンススタート時、次のラベルのMIDI用データを初期化（0クリア）すること
  にした。
program_number
midi_panpot
midi_flag
bank_address
knr_PBend_BF

●シーケンススタート時、次のラベルのワークエリアを初期化（0x0080）することに
  した。
midi_master_volume
midi_volume
midi_expression
noteon_master_volume
total_volume

●sound initコマンドでワークエリアが初期化されていないというバグを修正。
  これはバグといっても表面化していません。

●フェード中にポーズをかけるとポーズ中であるにもかかわらず、内部的には音量
  減衰がストップしないというバグを修正。これでなにがマズいかというと、
  「フェード中にポーズ→しばらく待つ→ポーズ解除」で曲が終わってしまってい
  るということがある。

●次のような条件のリクエストコマンドに耐えるようにした。
sequence volume > sequence start > sequence volume(fadeout) > sequence volume
 > sequence start

;=======================================================
;	ver-2.07 への履歴
;=======================================================

●シーケンスボリュームのワークが発音管理番号０～7まで一緒になってしまって
  いたというバグ（2.06で出現。それ以前は問題なし。エンバグです）を修正。

;=======================================================
;	ver-2.10 への履歴
;=======================================================

●スロットアサインのアルゴリズムが新しいものになりました。以前のものとは
  まったくちがいます。また、スロットが空いているかどうかをリリースレベル
  で判断するようにしました。リリースを見るプログラムは LEVEL 2 INT内で動
  作しています。
  くわしくはサウンドドライバ2.10のプログラムドキュメントを参照してください。

●マップチェンジ時のプチノイズを解消。しかし、SCSPの出力レベルをプログラム
  で減衰させるという手法を用いているため、演奏中にマップチェンジ、エフェク
  トチェンジを行ってはなりません。
  必ずシーケンスストップの状態でなければなりません。

●note onより先にpitch bendが入ると反応しないというバグ（？）を修正。

●トーンエディタからチェックボックスをマークしてもモジュレーションが反応しな
  いというバグを修正。

●FMとPCMの判別が正確でなかったという致命的なバグを修正。

●レーシングコントロール用インターフェースのベースアドレスを 0x0007c0から
  0x006f00へ移動。

●スロットの状態（出力レベル）を0x07c0からの32バイトにストアするようにした。

●ダイナミックフィルタがまったく効いていなかったというバグを修正。
