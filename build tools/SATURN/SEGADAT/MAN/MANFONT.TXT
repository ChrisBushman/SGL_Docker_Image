1.フォントファイルについて
  サターン上にて文字表示を行うためのビットマップフォントです。
  提供するフォントファイルには、8x16ドットで１バイトコードフォントと、
  16x16ドットで2バイトコードのJISコードセットの漢字フォントを用意して
  います。このコードセットはJIS(Japan Industrial Standard)規格
  JIS X 0208-1983準拠となっています。

2.フォントの仕様
　・1バイトコードフォント　　8x16ドット
                                       　　　　ASCIIコードフォント
　　　　　　　　　　　　　　　　　　　　  　　　　　　カナフォント
　
　・2バイトコードフォント　16x16ドット　　　　JIS第一水準漢字フォント
　　　　　　　　　　　　　　　　　　　　　　  JIS第二水準漢字フォント

3.提供ファイル一覧

      ┌──────────────┬───────────┐
      │　　　　フォント名称        │フォントファイル名    │
      ├──────────────┼───────────┤
      │ASCIIフォント               │ascii.fon             │
      │ASCII + カタカナフォント    │kana.fon              │
      │JIS第一/第二水準漢字フォント│kanji.fon             │
      └──────────────┴───────────┘
  
4.ファイル形式
  ・ascii.fon, kana.fon
  　先頭から16バイト単位でフォントデータが入っています。

 　　文字コード　　　00h            01h           02h                 FFh
               ┌──────┬──────┬──────┬┬─┬──────┐
   　　フォント│  16バイト  │  16バイト  │ 16  バイト ││  │  16バイト  │
       データ  └──────┴──────┴──────┴┴─┴──────┘

　　　　　フォント位置の計算式
                    フォント位置＝文字コード　×　16

  ・kanji.fon
    JIS第一水準、第二水準漢字のフォントです。
    先頭から32バイト単位でフォントデータが入っています。

　　JISコード　　　2121h         2122h        2123h               7e7eh
              ┌──────┬──────┬──────┬┬─┬──────┐
　　　フォント│  32バイト  │  32バイト  │ 32バイト   ││  │  32バイト  │
      データ  └──────┴──────┴──────┴┴─┴──────┘

　　　　　JISコードからのフォント位置の計算式

　　　　　　　　フォント位置＝(JH-21h)×(7eh-21h+1)+(JL-21h)

　　　　　　　　　　　　　　　　　　　JH:JISコードの上位バイト
　　　　　　　　　　　　　　　　　　　JL:JISコードの下位バイト

5.修正履歴

    Ver.1.00 -> Ver.1.01への変更点
    カナフォントファイル  kana.fon中、5Ch '￥' (Yenマーク)
    および 7Eh '～'(チルタ)が、ASCIIフォントファイル ascii.fonと
    同一となっていたため、JIS規格に準拠するよう正しいデータに修正しました。
